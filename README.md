# 📺 Netflix Movies and TV Shows - Exploratory Data Analysis

## 🎯 Objective
Analyze Netflix's catalog to find insights on content trends, genres, and countries.

## 📊 Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook

## 📦 Dataset
[Kaggle: Netflix Movies and TV Shows Dataset](https://www.kaggle.com/datasets/shivamb/netflix-shows)

## 📈 Key Insights
- Movies are 70% of Netflix content.
- USA and India dominate the platform.
- Drama and Comedy are the top genres.
- Rapid content growth in 2019–2021.
- Most shows are rated TV-MA and TV-14.

## 🧠 Skills Demonstrated
- Data Cleaning & Preprocessing
- Visualization & Storytelling
- Exploratory Data Analysis (EDA)

## 👨‍💻 How to Run
1. Clone this repo
2. Open `Netflix_EDA.ipynb`
3. Run all cells
